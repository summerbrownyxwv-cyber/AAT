## 打开网站

双击根目录的 **启动预览.command**。需要 Node.js 22 或更新版本；本机已有运行环境，无需安装依赖。

也可在本目录执行 `npm run preview`，默认地址为 http://127.0.0.1:4196/ 。首页进入 `website-code/index.html`，旧版页面地址在本地预览中会自动转入对应新地址。请通过预览入口访问，直接双击网页文件会影响模块与三维内容加载。

## 验证与部署

- `npm run check`：检查页面、模块、资源路径和位图校验值。
- `node website-code/scripts/check-site-experience.mjs`：检查联系页原大图 / 动态 / 三图入口结构、四业务联系方式、表单尚未发送反馈、19 款独立产品说明、店型入口、AI 准确率隐藏、共享页脚及静态和动态视频的无控件循环播放配置。
- `node website-code/scripts/check-home-motion.mjs`：检查首页图片轮播的自动播放、手动暂停、焦点、可见性与减少动态效果行为。
- `node website-code/scripts/check-product-catalog.mjs`：检查 19 款产品数量、20 份无损透明资源、文件校验、卡片边界与居中位置。
- `node website-code/scripts/check-product-carousel-motion.mjs`：检查拖动释放位置、阻尼中断、连续输入、首尾循环及横向滚轮。
- `node website-code/scripts/check-company-interactions.mjs`：检查业务组件点击展开、键盘操作、历程拖动及年份同步。
- `node website-code/scripts/check-section-cover.mjs`：检查叠屏尺寸计算、长章节滚动、减少动态效果及清理行为。
- `node website-code/scripts/check-hero-migration.mjs`：检查首页影片引用、视频文件校验值及移至产品页的三维展示滚动映射。
- `node website-code/scripts/check-honors-cooperation.mjs`：检查荣誉切换、展开与生产合作圆线状态。

浏览器布局、交互复测范围和当前截图统一见 `notes/responsive-check`，以该目录的当前记录为准；浏览器尺寸模拟不等于实体设备测试。

`npm run build` 生成 `website-code/dist`，可将该目录内容上传至静态网站服务器。发布内容包含入口页、assets、content、website-code；不包含 notes。交付包根目录不保留两套 public/dist 素材副本。

## 图片处理

网页独立 PNG/JPEG 已转为 WebP，逐张验证尺寸、RGBA 解码像素及色彩、EXIF、XMP 信息。已有 WebP 仅在无新增像素损失且文件更小时替换；既有有损 WebP 保留其现有画质，不宣称恢复原始信息。566 份来源位图去重后为 499 张，体积由 752.90 MB 降至 607.44 MB，减少约 19.3%。详细对应关系见 `content/asset-map.json`。SVG 保留矢量，三维模型内嵌纹理保留原模型格式；不保留旧版本和原图备份。

首页上传影片保留原 H.264 视频码流、1920×1080 分辨率和 25 帧帧率，仅整理容器信息、移除静音展示不使用的音轨并将索引前置。文件由 17,532,641 字节降至 17,516,809 字节，约减少 0.09%，未重新压缩画面；校验记录在 `content/home-video.json`。新增的首页影片封面为无损 WebP，不属于上述 566 份来源位图。
